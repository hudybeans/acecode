# 分级问答

## 首轮：三个问题

用 ACECode 的 `AskUserQuestion({"questions":[...]})` 一次发出三组单选，`multiSelect=false`。每题含 question、header、options，每项 option 含 label 和 description。保留以下选项文案，解释写在 description。已有答案直接沿用，继续草稿不重复问。

| 问题 | 三个选项（label） |
| --- | --- |
| 主题定制程度 | 快速定制：主页和样式 / 高级定制：主页、会话页和样式 / 深度定制：主页、会话页、聊天卡片定制 |
| 主题模式 | 位图，依赖图形生成工具 / 矢量图（不使用图形生成工具） / 使用自带贴图（不使用图形生成工具） |
| 风格基座 | 白天模式 / 黑夜模式 / 不拘泥于白天还是黑夜 |

快速记录为 `scope="quick"`，高级为 `advanced`，深度为 `deep`；素材记录为 `asset_mode="bitmap"|"vector"|"local"`；风格偏好为 `style_base="light"|"dark"|"free"`。确认色系时才把实际 `mode` 固定为 light/dark，free 不代表系统自动切换。

自带贴图是用户提供的本地图片，不是内置素材库。询问实际图片/路径和它们对应的区域，只索取当前范围的素材。没有图片可先做框图，但不能把占位框图安装成最终背景。

## 细节：三档建议加其他

分批提问，遵守工具支持的问题数量。每题给三项建议并保留宿主自带的“其他”输入；宿主不提供时加入第四项“其他”，选择后收集具体值。不把点选“其他”当成已设置值。

1. **首页文本框透明度**：10%（清晰）、30%（通透）、50%（强调壁纸）。只改变底色，不影响文字、图标。
2. **首页图片主色调**：按本次主题给三项色名和具体 HEX。第一项沿用用户指定主色，另两项给协调的柔和/鲜明方向；其他允许色名或 HEX，先确认实际 HEX。不把所有主题固定为紫色。
3. **首页图片透明度**：0%（鲜明）、30%（柔和）、60%（淡雅）。
4. **会话图片主色调**（仅高级/深度）：与首页相同、较淡、较深三项协调的具体色名和 HEX，允许其他。
5. **会话图片透明度**（仅高级/深度）：0%（鲜明）、30%（柔和）、60%（淡雅）。

深度模式再确认用户消息背景素材及主色/透明度，同样给三项建议和其他。③只作用于用户发送的消息，不作用于 AI 回复、系统提示、工具卡片或整个聊天页。

透明度是 **0%=不透明，100%=完全透明**。接受 0–100 的自定义百分比，超范围/非数字先澄清；30% 透明写入 `opacity=0.7`。

| 用户设置 | appearance 参数 |
| --- | --- |
| 首页文本框透明度 | `home_composer_opacity` |
| 首页背景主色 / 透明度 | `home_background_color` / `home_background_opacity` |
| 会话背景主色 / 透明度 | `session_background_color` / `session_background_opacity` |
| 用户消息背景主色 / 透明度 | `user_message_background_color` / `user_message_background_opacity` |

图片主色用于素材创作和图片下方的底色；透明度增加时逐渐露出该底色。贴图改色需遵循用户选择，不声称底色参数能把任意照片整体换色。

## 保留旧参数与真实确认

图标色 `logo_color`、首页标题色 `home_title_color`、通顶 `extend_to_titlebar` 始终可用，不受定制等级限制。重新询问透明度、切换素材模式、修改局部背景时不得删掉它们。基于 status 和已确认方案合并修改，再传回完整 appearance；用户明确恢复默认时才移除对应覆盖。深色通顶仍使用白色右侧按钮。

问答只形成需求，不替代 theme_create 的色系和原型确认。取消、超时或自动选择不允许安装。
