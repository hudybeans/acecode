## Purpose

让 Desktop 用户在原生目录选择器不可用或调用失败时，仍能通过现有 Web 目录选择器打开工作区，并明确原生与 Web 选择的取消、成功和后续失败行为，避免重复弹窗或静默中断。

## ADDED Requirements

### Requirement: 工作区原生目录选择失败自动回退

首页“打开现有目录”和侧栏“添加项目” SHALL 优先调用可用的原生目录选择器。原生调用抛出异常、返回错误或返回非取消且无法使用的结果时，系统 SHALL 自动打开一次 Web 文件夹选择器，让用户继续选择 daemon 所在机器的目录，不把已恢复的原生错误作为操作失败提示。没有原生入口时 SHALL 直接使用同一 Web 选择流程。

#### Scenario: 原生目录工具缺失
- **WHEN** 原生目录选择报告 zenity/kdialog 等目录选择工具不可用
- **THEN** 自动打开 Web 文件夹选择器，确认后注册所选目录并返回工作区

#### Scenario: 原生调用或结果无效
- **WHEN** 原生调用抛出异常，或者返回无法解析的 JSON、缺少工作区标识的非空结果
- **THEN** 自动打开一次 Web 文件夹选择器

#### Scenario: 原生成功
- **WHEN** 原生选择返回有效工作区
- **THEN** 返回该工作区，不打开 Web 选择器；原有补注册失败不影响已经有效的选择结果

#### Scenario: 没有原生入口
- **WHEN** 普通浏览器页面打开现有目录
- **THEN** 直接通过 Web 文件夹选择器选择并注册目录，不调用原生 REST 对话框

### Requirement: 保留取消与最终失败语义

用户取消原生或 Web 选择时，系统 SHALL 结束当前打开目录操作，不注册目录，不再次打开其他选择器。Web 选择器或后续目录注册失败时 SHALL 保留该错误供现有调用方提示，不再次尝试原生或 Web 选择。

#### Scenario: 取消原生选择
- **WHEN** 原生选择返回空结果（包括 JSON null 或空字符串）
- **THEN** 操作结束，不打开 Web 选择器，不注册工作区

#### Scenario: 取消回退选择
- **WHEN** 原生失败后用户取消 Web 文件夹选择
- **THEN** 操作结束，不注册工作区，不提示已经恢复的原生错误

#### Scenario: Web 选择器失败
- **WHEN** 原生失败后 Web 选择器本身不可用或调用失败
- **THEN** 调用方收到 Web 选择器错误，且不会再次弹出选择器

#### Scenario: 回退后的目录注册失败
- **WHEN** Web 选择确认后的注册请求抛出异常或返回错误
- **THEN** 调用方收到注册错误，且不会重复选择或注册
