## Why

同一工作区的 A 会话打开文件后，B 会话会看到相同页签；关闭或编辑也作用于共享文件状态。此前 `guard-unsaved-file-navigation` 只补齐了未保存确认，没有完成用户要求的全部会话级工作状态隔离。本变更补齐整个范围。

## What Changes

- 文件页签、顺序、激活项、编辑与浏览位置归属当前会话，所有打开、关闭、刷新和异步回调遵守该归属。
- 文件树数据、展开、选中、滚动，以及右侧栏目、详情显示、最大化、尺寸分别缓存到会话。
- Git 基线、列表和 diff 缓存按会话独立，同一会话的导航列表与详情仍共享一份结果。
- 终端列表、激活项、显示与高度按会话恢复；PTY 后端记录所属会话，过滤列表并支持新建草稿的归属移交，切换保持进程运行。
- 新建入口使用独立临时归属，创建正式会话时一次性交接给新会话；已有会话只恢复自己的状态。
- 保留未保存修改的“取消 / 不保存 / 保存”，聊天草稿、变更页签和浏览器原有会话归属；修正此前将完整改造排除的范围说明。

## Capabilities

### New Capabilities
- `session-console-ownership`: PTY 的会话归属、列表过滤和草稿交接。

### Modified Capabilities
- `webui-side-panel`: 工作区内不同会话恢复各自的完整工作状态，取代同 cwd 共用状态。

## Impact

影响 `App`、`ChatView`、预览、文件树、Git 与终端组件及相关纯状态模块；扩展 PTY 注册表与 API，并同步 `docs/daemon-api.md`。不修改实际工作区文件的共享磁盘语义或主题、语言、默认 Shell 等应用设置。
