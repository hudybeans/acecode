## Purpose

让每个聊天会话可靠地持有自己的终端集合、当前终端和停靠状态，在会话切换和浏览器刷新时按归属恢复，并保证后台进程与输出继续运行。新建会话之前启动的终端可移交给正式会话，而不会被其他已有会话取得。

## ADDED Requirements

### Requirement: 终端会话归属

PTY 创建结果和查询 SHALL 提供所属 owner，指定 owner 的查询 MUST 只返回该 owner 的终端。界面 SHALL 恢复当前会话的列表与选中项，切换时不得终止其他会话的进程或将旧版无归属终端自动分配给当前会话。

#### Scenario: 同工作区终端隔离
- **WHEN** A 与 B 分别创建终端并来回切换
- **THEN** 各自只显示自己的终端，原进程保持运行且输出仍可恢复

#### Scenario: 刷新恢复
- **WHEN** 用户刷新当前会话的界面
- **THEN** 仅恢复属于该会话的终端并回放现有输出

#### Scenario: 临时终端移交与在途创建
- **WHEN** 新建入口产生的终端移交给新会话，且仍有未完成的创建请求
- **THEN** 已有与晚到终端均归属该新会话，后续新建入口及其他已有会话不获得这些终端

#### Scenario: 关闭单个终端
- **WHEN** 用户关闭当前会话的一个终端
- **THEN** 仅该终端被终止和移除，其他会话的终端和激活状态不变
