## Why

审核 PR #60 与 #61 时发现顶部导航新增左边距没有计入最小宽度，且 macOS 图形安装器与应用内更新器没有共用安装锁。需要在合并前修复边界问题，并让原生安装器回归测试进入 PR 检查。

## What Changes

- 保留侧栏图标对齐，修正窄窗口顶部导航的宽度预算。
- 支持可信应用在可写自定义目录内原位更新，以及带原生安装器的双架构签名 DMG。
- 图形安装器与应用内更新共用锁文件，拒绝异常文件类型、链接和不安全属主，获取锁时不得阻塞。
- 在 PR CI 中运行 macOS 原生安装器测试、双架构编译及离线发布脚本测试。

## Capabilities

### New Capabilities
- `macos-graphical-installation`: 自定义安装位置、可信 DMG、互斥安装与失败恢复；此变更取代旧变更中“仅标准目录”及“禁止 DMG”的限制。

### Modified Capabilities
无。

## Impact

涉及侧栏与顶部导航样式、macOS 安装器及更新器、打包工作流、脚本测试和发布文档；不发布版本、不调用生产签名或公证凭据。
