# 分级主题定制与离线预览

## Why

用户要求先选择主题定制程度、素材模式和风格基座，再确认背景主色及透明度；无法使用生图模型时仍能以 HTML 和 ACECode Browser 预览。当前主题只有首页图片，必须补齐会话和用户消息背景的实际数据链路。

## What Changes

- ai-theme 首轮同时询问快速/高级/深度定制、位图/矢量图/自带贴图、白天/黑夜/不限基座。
- 按范围询问首页输入框透明度、首页/会话背景主色与透明度，每题三档建议并支持其他输入。
- 提供离线 HTML 预览模板和素材渲染说明；矢量和自带贴图模式不调用生图工具。
- 主题增加可选会话、用户消息背景及背景/首页输入区透明度；用户消息背景不影响助手回复。
- 草稿确认、安装、图片读取、导入导出及 C# 工坊校验携带完整资源，保留三文件旧包兼容。

## Capabilities

### New Capabilities
- tiered-theme-customization: 分级问答、多素材模式与离线预览。

## Impact

内置 ai-theme skill 与 seed 版本、theme_create 和 ThemeStore、Web 主题加载和表面样式、工坊主题包校验、相关契约和测试。无需修改生图工具或发布新版本。
