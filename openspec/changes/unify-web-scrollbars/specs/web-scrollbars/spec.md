## Purpose

为 ACECode 的应用自有滚动容器定义统一的粗细滚动条、显隐与悬停反馈，让用户在会话、列表、编辑预览和嵌入文档中获得一致且容易点击拖动的滚动体验，并避免悬停导致内容重新布局。

## ADDED Requirements

### Requirement: 粗细滚动条共享一致规则

应用 SHALL 保留主会话 transcript 的粗常显滚动条，其余普通容器采用统一细样式。

#### Scenario: 主会话和普通面板
- **WHEN** 主会话、侧栏、设置或代码预览内容溢出
- **THEN** 主会话 MUST 保持粗常显，其他区域 MUST 采用统一细条颜色和圆角

### Requirement: 细条按模式显现并扩大操作范围

细条 SHALL 默认隐藏，在移入所属容器或键盘聚焦时显现，并允许容器明确选择常显模式。

#### Scenario: 悬停细滑块
- **WHEN** 指针移入细滚动条滑块或其透明命中边缘
- **THEN** 滑块 MUST 高亮并加粗，透明边缘 MUST 支持点击拖动，容器内容尺寸 MUST 不变

#### Scenario: 显隐与常显
- **WHEN** 指针离开默认细条容器且该容器无键盘焦点
- **THEN** 滑块 MUST 隐藏；明确设置常显的细条 MUST 保持可见

#### Scenario: 水平滚动与拖动
- **WHEN** 用户操作水平细条或拖动时指针离开轨道
- **THEN** 系统 MUST 使用同一套反馈并保持拖动有效，不能改变内容布局

#### Scenario: 触摸与兼容降级
- **WHEN** 设备不支持 hover 或浏览器不支持细滑块自定义外观
- **THEN** 系统 MUST 保留可用的原生滚动操作与可发现性，不因视觉效果禁用滚动

### Requirement: 特殊预览复用样式而保留滚动所有者

应用自绘标签滚动条和 PPT 文档预览 SHALL 复用共享尺寸与颜色规则；编辑模式 MUST 只显示负责交互的滚动条。

#### Scenario: 标签和嵌入文档
- **WHEN** 预览标签溢出或 PPT 缩放产生滚动
- **THEN** 滚动条 MUST 使用统一细样式，并保留标签拖动和文档缩放功能

#### Scenario: 编辑预览
- **WHEN** 代码预览进入编辑模式
- **THEN** 输入层 MUST 采用统一细条，下层只读渲染的滚动条 MUST 保持隐藏以避免重复
