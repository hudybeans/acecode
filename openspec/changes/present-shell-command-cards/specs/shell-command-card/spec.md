## ADDED Requirements

### Requirement: 统一 Shell 命令卡片
执行命令调用 SHALL 在主会话与子代理中使用相同 Shell 卡片，卡片内显示命令及输出预览，不再使用卡片外的 Ran 行配独立输出框。

#### Scenario: 查看已完成命令
- **WHEN** 显示已完成的 bash 调用或历史 Ran 记录
- **THEN** 默认可见 Shell 标题、已记录的命令与短输出，长内容可展开，复制获得完整已保存命令及输出

#### Scenario: 实时运行与失败
- **WHEN** 命令运行中、输出持续到达或执行失败
- **THEN** 卡片保持相同结构，保留运行/耗时及失败信息，展开状态不被后续输出重置

#### Scenario: 历史工具配对
- **WHEN** 结构化 Shell 结果同时有匹配的调用包装
- **THEN** 优先恢复完整命令参数而非截断摘要，调用去重仍生效，多个并行调用不串命令

#### Scenario: 缺失请求和其它工具
- **WHEN** 旧记录没有完整命令，或记录属于其它工具
- **THEN** 旧命令仅展示已有信息，其它工具继续使用原有专用展示

### Requirement: 交互和主题一致性
卡片 SHALL 使用现有主题与字体 token，支持键盘及桌面右键展开/收起，复制按钮 SHALL 不触发折叠。消息自动折叠的外层策略 SHALL 保持生效。

#### Scenario: 窄屏与主题
- **WHEN** 在明暗主题、中英文界面或 390px 窄屏查看长命令和长输出
- **THEN** Shell 卡片无页面横向溢出，命令/输出清晰分层，所有内容可通过展开与滚动查看
