## ADDED Requirements

### Requirement: 统一 Shell 命令卡片
执行命令调用 SHALL 在主会话与子代理中保留统一工具执行行，包含图标／运行状态、指令名、参数与指标。Shell 卡片 SHALL 仅作为该行展开后的命令及输出详情，不得替代或隐藏工具执行行。

#### Scenario: 查看已完成命令
- **WHEN** 显示已完成的 bash 调用或历史 Ran 记录
- **THEN** 默认可见原有工具执行行；点击或键盘展开后，行仍保留，下方显示 Shell 标题、完整已记录命令和输出，复制获得完整内容

#### Scenario: 实时运行与失败
- **WHEN** 命令运行中、输出持续到达或执行失败
- **THEN** 工具执行行保留运行/耗时及失败信息，详情继续使用 Shell 卡片，展开状态不被后续输出或完成事件重置

#### Scenario: 收起命令详情
- **WHEN** 用户点击工具执行行、Shell 卡片标题或桌面右键收起
- **THEN** 隐藏详情卡片并保留图标、指令名、参数和指标，不渲染重复执行行

#### Scenario: 历史工具配对
- **WHEN** 结构化 Shell 结果同时有匹配的调用包装
- **THEN** 优先恢复完整命令参数而非截断摘要，调用去重仍生效，多个并行调用不串命令

#### Scenario: 缺失请求和其它工具
- **WHEN** 旧记录没有完整命令，或记录属于其它工具
- **THEN** 旧命令仅展示已有信息，其它工具继续使用原有专用展示

### Requirement: 交互和主题一致性
卡片 SHALL 使用现有主题与字体 token，支持键盘及桌面右键展开/收起，复制按钮 SHALL 不触发折叠。消息自动折叠的外层策略 SHALL 保持生效。

#### Scenario: 窄屏与主题
- **WHEN** 在明暗主题、中英文界面或 390px 窄屏查看长命令和长输出
- **THEN** Shell 卡片无页面横向溢出，命令/输出清晰分层，所有内容可通过展开与滚动查看
