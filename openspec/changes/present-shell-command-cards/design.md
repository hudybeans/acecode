## Context

`ToolBlock` 被主会话与子代理的 `TranscriptItems` 复用。当前仅 `tool === 'bash'` 时把 args.command 放入展开文本，历史结构化结果的 args 为空，配对阶段丢弃工具调用包装导致命令缺失。

## Goals / Non-Goals

- 按参考图使用普通字重 Shell 标题、等宽命令与输出、主题色浅底和圆角边框。
- 默认显示命令和短输出；较长内容在预览尾部渐隐，展开后读取完整的已保存内容。
- 运行、完成、失败、实时增量与历史恢复都共用同一卡片；复制不丢失已记录命令。
- 不修改命令执行行为，不取消用户刚配置的消息自动折叠策略，不重排其它工具样式。

## Decisions

1. 在 ToolBlock 添加 Shell 专用分支，识别规范 bash 工具与历史 Ran 摘要；其它工具继续既有 ActivityLine 与专用内容框。
2. 提取命令展示数据为纯函数，分开保存命令、输出与复制文本。旧调用/结果合成项额外保留结果原文，避免 Shell 输出重复包含调用包装。
3. 配对时只为 Shell 调用补齐缺失的工具名和参数；按既有 call id 归属处理，并且不覆盖已有实时参数、不修改原始历史。
4. 展开状态仍由 ToolBlock 唯一管理，键盘、标题点击与桌面右键菜单使用同一状态；审阅时沿用暂停滚动跟随回调。
5. 采用主题 token，缩略区域按实际内容溢出显示渐隐；完整态仅内容区域滚动，适配窄屏与大字号。

## Risks / Trade-offs

部分旧记录没有完整请求，只能展示现有摘要或明确缺失提示，不推测命令。默认预览增加少量卡片高度，但长内容有明确上限，仍接受外层消息折叠与历史窗口管理。
