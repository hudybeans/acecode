## Why

执行命令目前以外部 `Ran` 行和独立输出框展示，命令容易被截断，部分历史记录展开后甚至只显示输出。用户要求统一为参考图中的 Shell 卡片。

## What Changes

- 命令调用显示为单一 Shell 卡片，卡片内排列命令与输出，默认显示紧凑预览，长内容渐隐并可展开。
- 复用现有复制、工具折叠状态、运行状态、失败信息与主会话/子代理共享入口。
- 历史工具包装与结构化结果合并时恢复已记录的命令参数，避免只剩输出或把截断摘要当完整命令。

## Capabilities

### New Capabilities
- `shell-command-card`: 实时与历史执行命令的统一卡片展示。

### Modified Capabilities

## Impact

仅修改 WebUI 共享工具展示与历史投影，无后端协议变更。其它工具、文件 diff、提问结果及消息自动折叠偏好保持既有职责。
