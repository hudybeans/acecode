## Why

执行命令保留原有“图标、指令名、参数”的工具执行行，仅将展开后的命令和输出内容调整为参考图中的 Shell 卡片。历史记录展开时也必须保留已记录的完整命令。

## What Changes

- 命令调用默认保留统一工具执行行及折叠入口；展开后在行下方显示 Shell 卡片，卡片内排列完整命令与输出，长内容可滚动查看。
- 复用现有复制、工具折叠状态、运行状态、失败信息与主会话/子代理共享入口。
- 历史工具包装与结构化结果合并时恢复已记录的命令参数，避免只剩输出或把截断摘要当完整命令。

## Capabilities

### New Capabilities
- `shell-command-card`: 实时与历史执行命令的统一卡片展示。

### Modified Capabilities

## Impact

仅修改 WebUI 共享工具展示与历史投影，无后端协议变更。其它工具、文件 diff、提问结果及消息自动折叠偏好保持既有职责。
