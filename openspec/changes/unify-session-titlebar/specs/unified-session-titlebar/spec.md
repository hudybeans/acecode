## ADDED Requirements

### Requirement: 会话标题与操作合并到窗口顶栏
应用 MUST 在顶栏同一行显示当前会话标题、工作区和操作，主会话内容区不再额外占用标题行。

#### Scenario: 查看会话
- **WHEN** 用户进入会话
- **THEN** 标题、轨迹和竖三点等按钮出现在 41 px 顶栏中，三点紧邻控制台左侧，功能组与窗口控制组间隔 40 px

#### Scenario: 首页和原生 macOS
- **WHEN** 用户返回首页或进入 macOS 全屏
- **THEN** 不残留上个会话的标题和操作，并保留原生三灯的窗口/全屏避让行为

#### Scenario: 悬停图标及面板入口
- **WHEN** 用户悬停顶部可操作图标
- **THEN** 显示与窗口控制按钮一致的圆角悬停底块，且会话操作组不再额外显示面板恢复按钮

### Requirement: 三点菜单统一会话入口
系统 MUST 将侧边聊天和查找放入带原图标的竖三点菜单，并保留原会话操作、只读限制和确认流程。

#### Scenario: 执行菜单操作
- **WHEN** 用户选择侧边聊天、查找或既有会话操作
- **THEN** 操作作用于菜单所属会话且仅执行一次，菜单关闭，焦点和原生拖动不冲突

#### Scenario: 菜单外按下后开始窗口拖动
- **WHEN** 菜单打开且用户按下菜单之外的任意区域，包括标题栏
- **THEN** 菜单在按下时关闭，不依赖后续 click，原生拖动及所点按钮仍可正常工作

### Requirement: 菜单分隔线独立于按钮
共享菜单 MUST 使用独立直线分隔各组，不能因按钮圆角产生弧形。

#### Scenario: 危险操作分组
- **WHEN** 任意共享右键菜单显示归档或删除等危险操作
- **THEN** 分隔线保持直线并使用边框色，按钮保留原圆角和危险文字颜色
