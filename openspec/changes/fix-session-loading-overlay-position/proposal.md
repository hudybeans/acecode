## Why

读取聊天记录和恢复会话运行环境使用了两个不同层级的加载遮罩。记录先读取完成时，运行环境恢复提示在底部输入区内居中，产生加载卡片突然下移的现象。

## What Changes

- 合并当前会话的聊天记录加载、运行环境恢复及失败反馈，只保留一个挂在会话主列中的遮罩。
- 无论哪个异步阶段先完成，加载提示都以会话主列为定位范围；失败状态优先展示。
- 保留恢复期间的发送、队列发送和实时订阅保护，以及已加载的历史数据。
- 补充阶段完成顺序、遮罩挂载层级和浏览器布局验证。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `session-resume`：增加 Web 会话加载和恢复反馈始终在会话主列居中的要求。

## Impact

涉及 `ChatView.jsx`、现有 `sessionContentLoading.js` 及相关前端测试；复用现有加载卡片和主题样式，无后端 API 或依赖变更。
