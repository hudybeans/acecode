## ADDED Requirements

### Requirement: Web 会话加载反馈始终以会话主列居中

系统 SHALL 在聊天记录读取、会话运行环境恢复及其失败状态下，只展示一个位于当前会话主列中央的内容遮罩。加载阶段切换 MUST NOT 将提示移入底部输入区。侧栏 MUST 保持可操作，恢复期间 MUST 保留发送及实时订阅保护。

#### Scenario: 历史记录先完成
- **WHEN** 用户打开尚未恢复的会话，历史记录已经读取完成但运行环境仍在恢复
- **THEN** 加载反馈继续显示在会话主列中央，直到运行环境恢复完成
- **THEN** 已加载的历史数据保持不变，用户仍可通过侧栏切换会话

#### Scenario: 运行环境先完成
- **WHEN** 会话运行环境已经恢复但历史记录仍在读取
- **THEN** 内容遮罩继续在会话主列中央显示，直到历史记录读取完成

#### Scenario: 任一阶段失败
- **WHEN** 历史记录读取或可写会话的运行环境恢复失败
- **THEN** 同一会话主列遮罩显示失败反馈，不能被另一阶段的加载状态覆盖

#### Scenario: 输入区高度和面板变化
- **WHEN** 输入区被问题卡片替换、输入区高度变化，或显示右侧预览面板
- **THEN** 加载反馈仍以可见会话主列居中，不能以输入区、侧栏或右侧面板为中心

#### Scenario: 只读外部会话
- **WHEN** 用户查看只读外部会话
- **THEN** 遮罩仅受历史记录加载或失败状态控制，不额外等待可写运行环境恢复
